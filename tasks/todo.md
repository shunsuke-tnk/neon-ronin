# NEON RONIN — 開発計画（完成）

横スクロール型アクションゲーム。雨に濡れたネオンの帝都を駆ける女浪人「骸（むくろ）」の居合アクション。
グラフィックは GPT-image-2 / gpt-image-1 で生成したプロ品質のスプライト・背景＋ Canvas 2D の発光演出（加算合成トレイル・パーティクル・グリッチ・ヒットストップ）。

## 遊び方

```bash
cd ~/開発/action-game
npm install      # 初回のみ
npm run dev      # 開発サーバー（http://localhost:5173）
npm run build    # 配布用の単一HTML（dist/index.html）を生成
```

- 配布物 `dist/index.html`（約4.5MB）は**ダブルクリックで起動**。画像も埋め込み済みでオフライン動作。
- 操作: 移動 ←→/AD ／ ジャンプ Z(二段) ／ ダッシュ Shift ／ 斬る X・J ／ 武器切替 C ／ 残刃（必殺）B ／ ポーズ Esc ／ ミュート M

## 確定デザイン（ワークフローで4案統合 → NEON RONIN 採用）

- 主人公: 骸（逆光ネオン）／ 武器5系統（緋月・雷牙・黙・焔華＋必殺「残刃」）
- レベリング2層: 魂片→レベルアップ→3択強化カード（ローグライト）／ 電脳魂で永続強化
- ステージ5＋各ボス（雨曝・轟雷・狐火・双牙・天守零式）
